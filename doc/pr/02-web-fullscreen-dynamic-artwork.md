# 标题

feat(fullscreen): 添加动态封面渲染效果与可选提供方接口

# 正文

为 Web 全屏播放器添加动态封面显示、实时封面区域镜像、渐变羽化及背景光晕，并通过可选的 `window.aonsokuDynamicCover` 接口获取素材。默认不安装视频提供方，因此保持静态封面并隐藏动态封面开关；不会承诺开箱即用的视频生成能力。

- 在全屏根节点绘制背景光晕，避免横竖屏布局和桌面侧栏裁切效果。
- 根据封面实际显示区域采样并生成 4% 镜像边缘，通过渐变遮罩与柔化衬层过渡到背景。
- 将素材获取与生成需求分离，复用已有方形／竖版视频，按静态、相机运动、深度运动阶段升级。
- 校验封面、格式和模式；通过原提供方释放租约，处理切歌、卸载、后台和减少动态效果设置。
- 动态封面默认关闭；共享设置支持启用与重置，补充 18 种语言文案及提供方契约说明。

## 验证

- TypeScript 类型检查及 Vite 生产构建通过。
- Vitest：123 个测试文件、1,303 项检查通过；其中 15 项覆盖提供方缺失、静态回退、需求与租约释放、失败重试和不匹配素材。
- Cypress headless：全屏页面、移动布局及全屏内容共 9 项检查通过。
- 变更的 TypeScript／TSX 文件通过 Biome lint，18 个语言目录包含动态封面设置文案。

此 PR 仅包含渲染效果和接口，不引入 Tauri，也不接入 Electron 或 iOS 视频生成服务。真实视频提供方的端到端播放需在后续宿主接入时验证。与 iOS 锁屏 PR 没有代码依赖，也不将 Web 页面嵌入原生 iOS 应用。
