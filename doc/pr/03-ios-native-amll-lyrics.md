# 标题

feat(ios): 为原生播放器添加 AMLL 风格歌词动效与不限行排版

# 正文

将 Web AMLL 的主要布局和动效迁移到原生 iOS 同步歌词：逐行弹簧位移与缩放、距离模糊、当前句高亮、播放跟随和手动浏览暂停。歌词仍使用原生滚动与播放服务，不嵌入 Web 页面。

- 罗马音位于原文上方，译文位于下方，原文使用更大字号并通过缩放和亮度突出当前句。
- 各文字层使用相同明确宽度下测量和绘制的不限行 UILabel，长文本、显式换行和超长单词完整显示。
- 完整文本高度决定布局，动效仅作用于渲染，避免缩放反馈导致断行和行高跳动。
- 支持逐行错落弹簧、35% 视口对齐、片头等待点、点击跳转及手动浏览后的跟随恢复。
- 隐藏歌词停止播放跟随，减少动态效果设置禁用模糊和缩放。

## 验证

- arm64 iOS 模拟器应用构建通过。
- `bash scripts/test-ios-lyrics-motion.sh`：AMLL 动效数学回归检查通过。
- `bash scripts/test-ios-lyrics-layout.sh`：模拟器 588 项排版检查通过，覆盖多种宽度／字号、翻译开关、高亮切换、显式换行和超长单词。
- `node scripts/check-ios-strings.mjs` 通过。

此实现对齐主要 AMLL 体验，尚非与 Web 完全一致：原文保持 semibold 以稳定断行，跳转使用快速弹簧，缩放延迟与部分曲线有所差异，也未接入拖动进度的歌词预览。本 PR 保留 deploy 已确认的行为，不扩展这些交互。真机滚动、高亮切换和跳转体验由维护者验收。
