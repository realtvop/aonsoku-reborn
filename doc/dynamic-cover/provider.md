# Web 全屏动态封面提供方接口

此分支包含渲染效果和 TypeScript 接口，不包含 Tauri、Electron 或 iOS 视频生成桥接。默认不安装提供方，播放器沿用静态封面，隐藏动态封面开关。

宿主可在渲染器启动前安装 `window.aonsokuDynamicCover`，实现 `DynamicCoverProvider`：`getCapabilities`、`acquire`、`release`，以及可选的 `registerDemand` / `releaseDemand`。提供方应返回浏览器可播放且不包含音轨的视频 URL，并通过租约保护文件。提供方应将需求绑定到当前封面并校验宿主会话，禁止向页面暴露带凭据的源 URL 或任意本地文件读取接口。

消费者不指定生成像素尺寸，复用方形或竖版素材并裁切成正方形。静态、相机运动和深度运动按阶段升级；错误歌曲、格式或静态请求收到动态素材时释放租约并拒绝显示。窗口隐藏、封面切换、组件卸载时释放需求和素材。

前景使用封面区域采样生成 4% 镜像边缘、渐变遮罩及柔化衬层，背景光晕在全屏根节点绘制。此 PR 不修改原生 iOS 播放器，也不依赖 iOS 锁屏 PR；后续平台提供方可单独接入此接口。
